# Política de Segurança

O Via Sacra não coleta dados pessoais nem possui servidores próprios: o app só baixa JSON estático
do próprio repositório. Ainda assim, levamos segurança a sério.

**Relate vulnerabilidades de forma privada** pela aba
[Security → Report a vulnerability](https://github.com/julia-flima/ViaSacra/security/advisories/new).
Não abra issues públicas para falhas de segurança. Responderemos em até 7 dias.

Versões suportadas: a última release publicada.
