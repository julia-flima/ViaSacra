# Catálogo de Arte Sacra em Domínio Público

20 obras clássicas mapeadas para os 20 Mistérios do Rosário. Todas de artistas falecidos há mais de 70 anos; a licença de cada arquivo foi **verificada automaticamente** no Wikimedia Commons (`extmetadata.LicenseShortName`) por [`tool/fetch_sacred_art.py`](../tool/fetch_sacred_art.py), que também baixa as miniaturas (≈ 960 px) para `app/assets/art/`.

No app, cada imagem exibe a legenda: *título — artista, ano. Acervo. Domínio público (Wikimedia Commons)*, com link para a página do arquivo.

Para trocar uma obra: edite `tool/sacred_art_catalog.json` (campo `busca`, ou fixe `arquivo_commons`) e rode `python tool/fetch_sacred_art.py --only <id>`.
