## Novidades

Pré-release focada em desempenho, principalmente na versão Web.

- **Bíblia sob demanda na Web**: os livros são carregados só quando abertos, e a abertura do app fica mais rápida.
- **Rolagem mais leve**: listas longas carregadas aos poucos, menos redesenhos ao trocar o tema e imagens otimizadas.

## Correções

- As gravações no banco de dados passam a usar transações seguras.
- O service worker da versão Web não serve mais arquivos desatualizados.
